# Public Safety

This repository is public technical evidence.

## Allowed

- synthetic data;
- SQL examples;
- architecture;
- runbooks;
- generated sample outputs;
- model/data governance templates;
- public documentation.

## Forbidden

- real banking data;
- real insurance or health data;
- real client data;
- employer data;
- CVs;
- cover letters;
- job trackers;
- salary targets;
- private school documents;
- secrets;
- tokens;
- credentials;
- private hostnames or IP addresses;
- production decisioning claims.

## Review checklist

Before every public release:

- [ ] data is synthetic;
- [ ] no credentials are committed;
- [ ] screenshots are sanitized;
- [ ] no application material is present;
- [ ] README does not overclaim production readiness.
